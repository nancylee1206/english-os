# English OS

English OS is a 90-day intensive listening and shadowing course.

This repository is prepared for GitHub Pages:

https://nancylee1206.github.io/english-os/

Open `index.html` to start. Day01 is available now and stores sentence progress in the browser with `localStorage`.

Current structure:

- `index.html`: home page and course list
- `day01.html`: Day01 listening lesson
- `.nojekyll`: keeps GitHub Pages serving files as plain static assets

Future days can be added as `day02.html`, `day03.html`, and so on, then linked from `index.html`.
